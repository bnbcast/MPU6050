# MPU-6050 + ESP32 Motion Lab

Explore a virtual MPU-6050 in 3D: rotate and shake the board, inspect simulated accelerometer and gyroscope readings, and learn how the ESP32 sensor sketch and separate Control Center fit together.

## What it does

- 3D MPU-6050 model you can rotate and shake
- Simulated accelerometer and gyroscope readings (X/Y/Z)
- Live motion charts and raw-value inspection
- ESP32 sensor sketch explanation and Control Center overview
- Clearly labeled simulation versus real hardware

## Stack

React 19 · Vite 6 · Three.js · ESP32 / Arduino · Sensor simulation

## Run locally

```sh
npm install
npm run dev
npm run build
```
